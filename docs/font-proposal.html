02字号阶梯与字重

2.1 字号阶梯（保留现值）

实测渲染 kicker 23px / h2 54px / body 29px（750 设计宽）。阶梯已与存量草稿观感对齐，保留不改值，仅修正 h2 的注释常数（48/750 与实测 54px 不符，值以实测为准）。

2.2 字重吸附（核心改动，修 F1/F2）

机制：新增纯函数 snapWeight(font, target) —— 在字体清单的 weights 真值数组里取最近档（同差取大）。标题请求 800：LXGW WenKai（300-700）吸附到 700，Noto Sans SC（有 800）保持 800。预览 CSS 变量与导出管线走同一函数，两侧严格一致。
用途字重
正文400（强调 500，仅全档字体）
板块标题700（吸附后）
主标题700–900（按档位吸附）
kicker / 序号700 + letter-spacing 0.06em

机制兜底：预览根节点加 font-synthesis:none，从引擎层面禁止伪粗——缺档时宁可细、不可糊。

04中西文混排

  • 盘古之白由模板文案手动保证——canvas 渲染无法自动插空隙，避免双倍空格；
  • 数字对齐：票档/价格/时间等数字密集文本加 font-variant-numeric:tabular-nums（Noto Sans SC 支持）；
  • 混排宽度差实测 3.4%：长条图不用两端对齐，左对齐下不构成视觉问题，不处理；
  • 等宽：JetBrains Mono 仅用于编号/账号类短文本，中文回落 YaHei 接受。

05缩放与响应式

长条图是固定画布导出物，无传统断点。三个真实场景均现状正确：预览 zoom（0.15–1.5，transform 缩放，字号为设计值）、导出倍率（1x/2x/3x 由管线处理）、3:4 画布（字号基准不变）。编辑器 UI 窄屏断点（<680px）已由 only-box.css 覆盖。

新增可读性闸门：caption 计算字号 <18px 时，从"仅提示"升级为"输入框红色描边 + 导出前确认弹窗"。

06加载与子集化

现状的分片按需加载（unicode-range，909 faces 中仅命中文本的分片激活）机制正确，不需要子集化改造。三点收紧：

  1. 默认字体预载：页面 load 后 2s 预载 Noto Sans SC 的 400/700 档，消除首次点选的秒级等待（不预载全部 43 款）；
  2. 档位精准加载：固定 400/700/900 改为按吸附后档位加载，不再发起注定失败的请求；
  3. 失败重试：提示条追加"重试"按钮（重新注入 link），网络恢复后无需刷新。

导出侧维持完整嵌入（PDF subset:false，PSD 打包 ZIP 安装）——准确优先于体积是既定产品决策。
