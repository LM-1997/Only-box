Only-box
快速协助摊主宣发

Only-box主要是为同人 Only 活动、新媒体运营和个人创作者准备的轻量图片工具箱。无需上传服务器，打开浏览器就能完成裁切、预览与导出。

Tools

当前可用工具

每个工具都附有操作教程和设置建议。第一次使用时，按页面中的步骤操作即可。

多宫格裁切

把一张主视觉切成 4、6 或 9 张 1000 × 1000px 图片。裁切框会自动匹配所选布局，并支持设置平台间隙、预览与打包下载。

立即进入工具 →

头像 Logo 预览

一次检查圆形、方形、圆角、透明通道、深浅背景与小尺寸表现，快速判断活动 Logo 是否适合作为社交平台头像。

立即进入工具 →

收款码合并图

导入微信和支付宝收款码，合并成一张横版 4:3 或竖版 9:16 图片。适合摊位打印、手机展示和电子屏使用。

立即进入工具 →

长图拼接

一次选择多张图片，按想要的顺序点按编号，再生成竖向或横向长图。支持继续添加、手机端排序和本地 PNG 导出。

立即进入工具 →

价目表生成器

填写品名和价格，自动排版成可打印的摊位价目表图片。支持上移下移排序、品名自动换行与省略号截断。

立即进入工具 →

摊位号牌生成

粘贴摊位清单，一键批量生成号牌与指引牌。可放活动 Logo 和主视觉背景图，摊位号自动放大到最合适字号，多张打包下载。

立即进入工具 →

打印排版 A4 拼版

把多张图片按网格排进 A4 竖版页面，支持裁切填满与留白适应两种模式，附裁切参考线，多页打包导出。

立即进入工具 →

海报文字模板

上传背景图或使用品牌渐变，输入标题副标题，三套排版模板一键切换，生成竖版宣发海报。

立即进入工具 →

多平台尺寸裁切

一张图分别裁出小红书、公众号、微博等平台比例，每个比例独立记忆裁切位置，勾选后打包导出。

立即进入工具 →

倒计时图生成

输入活动日期，生成“还有 N 天”宣发图，支持提前连更的多天系列批量出图，按自然日精确计算。

立即进入工具 →

场刊头像批量裁切

批量导入照片自动裁成方形头像，可逐张精调裁切范围，导出圆形（透明背景）或方形 PNG。

立即进入工具 →

批量证件生成

上传背景和头像框模板，导入姓名表格，批量生成摊位证、舞台证和嘉宾证图片。支持单条编辑、姓名文字层与 ZIP 导出。

立即进入工具 →

长条宣传图搭建器

先选 9:16 或 3:4 比例，再一页一页往里加封面、票务、时间轴、摊位等模块，把宣传长图的结构搭出来。

立即进入工具 →
